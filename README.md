# Roof Guide

A mobile-first roofing guide: a six-step walkthrough, a 3D house with tappable parts, a damage library with an inspection walk, and a pitch tool. Sources are cited in the guide.

- Site: https://jorellano.github.io/roofing/
- Roof measuring tool: https://jorellano.github.io/roofing/measure/ (copied from jorellano/roof-measure)

Plain static files, no build step needed to host. `app.js` is a pre-bundled React build of the guide.
